# Project Setup

This project requires you to installed `uv` for package manager. See the [UV Docs](https://docs.astral.sh/uv) for more information.

To setup this project is simple just init the virtual environment with `uv`

```bash
uv venv
```

Then install the required module from requirements.txt

```bash
uv pip install -r requirements.txt
```

After this then we can running either notebook or the application scripts.
